# Внедрение датасета этимологий (9574 иероглифа, русские поля)

## Вердикт: файл пригоден

- **9574 записи**, единая структура (все ключи во всех записях), без дублей символов.
- Русские поля почти полны: `definition_ru` — 99,4% (58 null), `hint_ru` — 93,5% (626 null, в основном редкие не-HSK символы), `type_ru` — 94,3% (541 null). Null-поля почти целиком приходятся на редкие совместимые радикалы в начале файла.
- **100% покрытие словаря приложения**: все 1800 уникальных иероглифов из HSK-сидов есть (сейчас встроенный словарь покрывает ~150 — карточка чаще всего показывает «нет данных»).
- Реальная IDS-декомпозиция (`⿰女子` и т.п.) для 99,3% записей; поле `matches` мэппит каждую черту на компонент — база для подсветки.
- Происхождение: Make Me a Hanzi (Arphic Public License — источник уже используется проектом и указан в шапке characters.ts) + добавленные русские поля.
- 6,4 МБ pretty-printed → ~3 МБ минифицированно. Храним in-memory на сервере (решение принято), в веб-бандл не идёт.
